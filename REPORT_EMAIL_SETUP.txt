REPORT EMAIL SETUP
==================

Admin Reports now supports "PDF + Email Report".

Recipient (fixed by the application):
the email address entered by the admin

The application needs an SMTP sender account. It does NOT contain or assume the sender's password.

1. Copy .env.example to .env
2. Fill in:
   SMTP_HOST
   SMTP_PORT
   SMTP_SECURE
   SMTP_USER
   SMTP_PASS
   SMTP_FROM
3. Run:
   npm install
   npm start

Example for Gmail / Google Workspace:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your-account@example.com
SMTP_PASS=YOUR_APP_PASSWORD
SMTP_FROM=your-account@example.com

The report button will generate a PDF, download it, and send the PDF plus CSV attachment to the fixed recipient.
If SMTP is not configured or the SMTP server rejects the message, the PDF still downloads and the page displays an email warning.
